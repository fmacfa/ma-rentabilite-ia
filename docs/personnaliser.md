# Remettre un bilan à votre nom

[← Accueil du projet](../README.md) · [Exemple de comparatif personnalisé en PDF](../exemples/comparaison-deux-biens.pdf)

Vous pouvez utiliser les bilans générés dans le cadre de missions rémunérées, les modifier et les remettre à vos clients sous votre propre nom. Ouvrez le lien de bilan préparé par votre IA. **Personnaliser le document** se trouve à côté du téléchargement, pour une estimation, une étude complète ou une comparaison de deux biens.

| Ce que vous choisissez | Où cela apparaît |
| --- | --- |
| Nom du cabinet ou de l’auteur | En-tête de chaque page et auteur du PDF |
| Logo depuis votre ordinateur, en PNG, JPEG, WebP ou SVG | En-tête de chaque page, avec ses proportions d’origine |
| Couleur principale, au sélecteur ou par code hexadécimal | Bandeau des chiffres clés, titres, filets et en-têtes des tableaux du PDF |
| Titre et introduction | Première page, pour expliquer au destinataire la question étudiée |
| Coordonnées, signature ou mention de votre choix | Pied de chaque page, à côté de la pagination |

Cliquez sur **Appliquer**, puis sur **Télécharger le PDF**. Pour retrouver votre charte lors d’une autre mission, cochez **Mémoriser** avant d’appliquer. Le navigateur conserve sur cet appareil le nom, le logo, la couleur et le pied de page. Le titre et l’introduction concernent le document ouvert. Le lien de calcul partagé contient les chiffres du dossier. Transmettez le fichier exporté pour que votre destinataire reçoive votre mise en page.

**Télécharger en Markdown** donne un fichier texte modifiable avec le titre, l’auteur, l’introduction, la signature et tous les calculs. Vous pouvez déplacer des sections, compléter votre avis ou reprendre les tableaux dans votre propre modèle. Pour repartir du bleu d’origine, choisissez **Rétablir le modèle initial**, puis **Appliquer**.

## Un message à copier dans votre IA

```text
Prépare un comparatif pour une présentation client à partir de ce guide
https://github.com/fmacfa/ma-rentabilite-ia

Le cabinet signe « Cabinet Démo ». La couleur est #284D82.
Le titre est « Deux appartements sur dix ans ». Je fournis mon logo.
Mets en avant l’effort d’épargne, puis le produit de la revente.
Garde toutes les formules et tous les chiffres en annexe.
Donne-moi le document modifiable et le PDF avec cette présentation.
```
